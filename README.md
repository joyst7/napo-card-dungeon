# ナポのカードダンジョン(仮)

Pyxel製のターン制ローグライク(プロトタイプ3b)。

- index.html: ブラウザで遊べる版
- main.py: Pyxel のソース。バランスの数値は、先頭の定数(ROOM_ITEMS, ENEMY_HP_PER_LV など)と ITEM_TABLE にまとめてある
- tests/: 動作確認のテスト。`python3 tests/run_all.py` で全部実行する
- tools/bot.py: 自動で遊ぶボット。バランス調整用

## ボットで難しさを測る

```sh
python3 tools/bot.py 80 1      # 30F本番を80回（数分かかる）
python3 tools/bot.py 100 0     # 10F練習を100回
```

クリア率、どの階まで行けたか、死因、階ごとの攻撃力・防御・HP・剣と盾の値、食料と草の残りなどが出る。
ボットは「部屋を全部まわって、敵を全部たおし、道具を全部拾う」ていねいな遊び方をする。逃げたり、敵に合わせて剣を持ちかえたりはしない。

2026-11-07時点の目安: 30F本番のクリア率 約30%(倒れるのは主に21F以降)、10F練習 約96%。
